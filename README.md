# KREA Engineering SA — Studio di ingegneria

Sito statico multipagina pronto per GitHub Pages.

## Struttura

- `index.html` — home
- `servizi.html` — servizi
- `chi-siamo.html` — chi siamo
- `contatti.html` — contatti
- `legale.html` — note legali, privacy e cookie
- `assets/style.css` — stile condiviso
- `assets/script.js` — menu mobile, pagina attiva e piccole animazioni
- `assets/krea-engineering.png` — logo ufficiale fornito
- `assets/hero-construction.png` — immagine hero generata per la home
- `assets/service-*.png` — immagini dedicate ai cinque servizi

## Prima della pubblicazione

Aggiornare in `contatti.html` e `legale.html` l'email, il numero di telefono, i link social e i dati legali reali. Il testo legale è una base editoriale e va verificato prima della pubblicazione.

Per GitHub Pages è sufficiente pubblicare la cartella nella root del repository e impostare il deployment da branch/root oppure tramite GitHub Actions.
